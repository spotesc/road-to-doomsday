# The Road to Doomsday

Every Marvel film and series in story order before *Avengers: Doomsday* (18 December 2026), with tick boxes.

- Story order follows Disney+'s timeline order.
- "Disney+ pick" marks the 15 titles on Disney+'s official Doomsday watchlist.
- Ticks are saved in your own browser, so everyone you share it with keeps their own progress.

Made by Spotesc.

## Running it

It's a plain static site: open `index.html`, or serve the folder with any static server. Hosted on Vercel.

## Editing the list

Everything lives in `titles.js`, in story order, split into sections.
